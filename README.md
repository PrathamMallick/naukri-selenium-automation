# Naukri Selenium Automation

A Java-based Selenium automation framework for automating selected Naukri workflows.

## Project Status

🚧 Work in Progress

This project is being built from scratch using Java, Maven, and Selenium WebDriver.

## Objectives

The project aims to automate and demonstrate:

* Naukri profile automation
* Resume upload and verification
* Job search and job extraction
* Job filtering based on user-defined criteria
* Job application workflows
* Application status tracking
* Automated verification of actions
* Logging and screenshots for debugging

## Tech Stack

* Java
* Maven
* Selenium WebDriver
* TestNG
* Git & GitHub
